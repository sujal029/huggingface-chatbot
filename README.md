# Hugging Face Chatbot

This repository contains a simple chatbot implemented using the Hugging Face API and the BlenderBot-3B model from Facebook. The chatbot can respond to user inputs in a conversational manner.

## Description
This project demonstrates how to integrate Hugging Face's API for chatbot functionality. It utilizes the `facebook/blenderbot-3B` model, a large conversational model from Facebook, to interact with users.

The chatbot accepts user input and generates natural language responses, allowing for simple back-and-forth interactions.

## Features
- Conversational chatbot using BlenderBot-3B.
- Integration with Hugging Face API.
- Chat history maintained for context.
- Easy setup and usage with Python.
